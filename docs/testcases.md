# zen-fs-gitee 测试用例文档

> 文档目的：以可执行、可追溯的方式验证需求与用例。依据 `testcase-writer` skill 规范编写。编号体系 `TC-`，关联 `FR-`/`UC-`（见 `requirements.md` / `use-cases.md`）。

## 1. 测试概述
- 范围（In Scope）：挂载、同步读、同步写（含 mtime sidecar）、删除、mtime 解析、快照、变更探测、修订号、与 zen-fs-sync 集成。
- 测试类型：功能 / 集成 / 回归。
- 环境与测试数据：使用 Gitee 测试仓库（token/owner/repo/branch 通过环境变量注入）；本地以 IndexedDB（浏览器）或 Node 内存实现跑通。
